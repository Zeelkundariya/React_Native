# Contributing Guidelines 🤝

Thank you for contributing to the React Native practice repository!

## 📌 Development Workflow

1. **Branching**:
   - Create a feature or practice branch from `main`:
     ```bash
     git checkout -b feature/your-practice-name
     ```

2. **Install & Run**:
   - Navigate to the specific project directory:
     ```bash
     cd my-practices_sdk57
     npm install
     npx expo start
     ```

3. **Code Quality**:
   - Verify TypeScript compilation without errors:
     ```bash
     npx tsc --noEmit
     ```
   - Keep components modular and readable.

4. **Commits**:
   - Write clear, descriptive commit messages adhering to standard conventional prefixes (`feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `chore:`).

5. **Submitting Changes**:
   - Push your branch and open a pull request against `main`.
