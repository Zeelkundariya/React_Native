# Assignments & Practical Exercises 📚

This workspace contains React Native and Expo coding assignments, component implementations, and feature experiments.

## 🚀 Getting Started

1. Navigate to the assignments directory:
   ```bash
   cd assignments
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch Expo development server:
   ```bash
   npx expo start
   ```

## 📝 Topics Covered

- Core React Native UI Components (`View`, `Text`, `Button`, `FlatList`, `Image`, `TextInput`)
- State Management and React Hooks
- Navigation and Deep Linking with Expo Router
- Native Device APIs and Asynchronous Tasks
