# Employee Management App 👥

A React Native and Expo application built for managing employee records, tracking details, and demonstrating state-driven workflows.

## 🚀 Getting Started

1. Navigate to the Employee project directory:
   ```bash
   cd Employee
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch development server:
   ```bash
   npx expo start
   ```

## 🛠 Features

- Employee profiles and listing
- Form validation and input handling
- Typed navigation and screens with Expo Router
