# React Native Practice Projects Repository

A collection of React Native and Expo applications, practice modules, assignments, and architectural implementations.

## 📂 Repository Structure

- **`my-practices_sdk57/`**: Modern Expo SDK 57 application featuring file-system operations, biometric authentication (`expo-local-authentication`), network status checking, API fetching, timer counters, and native tabs.
- **`my-practices/`**: Core Expo Router based practices exploring device sensors, sharing, notifications, and local storage.
- **`myApp/`**: Drawer and tab navigation template with contacts, clipboard, camera, location, and AsyncStorage integration.
- **`project/StudentManagementApp/`**: Full Student Management application featuring profile screens, student listings, and CRUD API interactions.
- **`Employee/`**: Employee management interface and state flow implementation.
- **`FieldSurveyApp/`**: Field surveying tool with offline data management and custom forms.
- **`AuthenticationApp/` & `auth/`**: Authentication implementations featuring secure credential storage and biometric flows.
- **`assignments/`**: Coding exercises and assignments covering core React Native and Expo concepts.

## 🚀 Getting Started

1. Navigate to the desired project directory:
   ```bash
   cd my-practices_sdk57
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the Expo development server:
   ```bash
   npx expo start
   ```

## 🛠 Tech Stack

- **React Native** & **Expo**
- **Expo Router** (File-based navigation)
- **TypeScript / JavaScript (ES6+)**
- **Expo Modules**: `expo-file-system`, `expo-network`, `expo-local-authentication`, `expo-secure-store`, etc.

## 📌 Practice Highlights

- Native file downloading and background tasks using `expo-file-system`
- Biometric security integration with `expo-local-authentication`
- Device network diagnostics and state tracking with `expo-network`
